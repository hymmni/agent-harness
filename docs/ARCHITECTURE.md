# Architecture

**(자리표시 — 실제 프로젝트 구조로 교체할 것)** 하네스를 프로젝트에 처음 적용한 뒤 각 절을 이 프로젝트의 실제 내용으로 채운다. 에이전트는 구조에 영향을 주는 작업 전에 이 문서를 읽는다. 인프라 정보(서버 주소, PC 구성)는 여기에 쓰지 않는다. 프로젝트 레포가 public일 수 있다.

## 1. 개요
무엇을 하는 프로젝트인지, 주요 기술 스택.

## 2. 구조
주요 디렉터리와 모듈, 각각의 책임.

## 3. 데이터·제어 흐름
입력에서 출력까지 데이터가 지나가는 경로. 필요하면 mermaid 다이어그램으로 그린다.

## 4. 설정과 실행
설정 관리 방식, 실행·학습·테스트 명령.
