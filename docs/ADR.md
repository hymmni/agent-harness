# Architecture Decision Records (ADR)

구조에 영향을 준 결정을 시간순으로 쌓는다. 결정을 바꿀 때는 기존 항목을 지우지 않고, 새 항목에 어떤 ADR을 대체하는지 적는다.

## 양식

```
### ADR-NNN: 제목
**결정**: 무엇을 하기로 했나
**이유**: 왜 그렇게 했나
**트레이드오프**: 무엇을 포기했나
```

---

> **(자리표시 예시)** ADR-001은 대부분의 프로젝트에 맞는 시작점이다. 이 프로젝트에 맞지 않으면 새 ADR로 대체한다.

### ADR-001: 프로젝트 단위의 독립 가상환경
**결정**: 가상환경(conda, venv 등)은 프로젝트 레포 루트에서 독립적으로 구성한다.
**이유**: 프로젝트마다 요구하는 라이브러리 버전이 달라, 환경을 공유하면 충돌한다.
**트레이드오프**: 새 프로젝트마다 환경을 따로 만들어야 한다.
